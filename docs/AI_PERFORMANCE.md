p99 偶发偏高来自 OpenAI Embedding API 冷启动或网络抖动；pgvector 命中时稳定在 80ms 以内。

## 2. SSE 流式首字延迟 (TTFB)

**测试方法：** `POST /api/chat/stream`，消息「你好」，测量首个 `event: token` 到达时间。

| 指标 | 本地 (dev) | 说明 |
|------|------------|------|
| 采样数 | 5 | 需有效登录 session |
| p50 | **840 ms** | 含 RAG + DeepSeek 首 token |
| p99 | 2062 ms | |
| errors | 0 | |

**验收目标：** p50 < 500ms → **本地 dev 未达标**（840ms）

**分析：**

- 本地 dev 含 Next.js 编译冷启动、DeepSeek API 跨境 RTT（上海/香港 → API）
- 生产 Vercel（hkg1）距 DeepSeek 路由更近，**预期生产首字 400–600ms**
- 自动化脚本对生产 SSE 需 `SESSION_SECRET` 与 Vercel 完全一致才能签发 cookie；建议在浏览器 DevTools → Network 对 `/api/chat/stream` 查看 `TTFB` 作生产验证

**分解（典型一次请求）：**

| 阶段 | 耗时 (约) |
|------|----------|
| RAG 检索 | 75–80 ms |
| Prompt 组装 + Agent 路由 | < 10 ms |
| DeepSeek 首 token | 350–750 ms |
| **合计** | **430–840 ms** |

## 5. 成本分析

基于 DeepSeek + OpenAI Embedding 公开定价估算。

### 单次操作成本

| 操作 | Token 量 | 单价 (约) | 单次成本 |
|------|---------|-----------|---------|
| Query Embedding | ~20 | $0.02 / 1M | ~$0.0000004 |
| Chat 生成 | ~500 | $0.14 / 1M (DeepSeek) | ~$0.00007 |
| 对话摘要 | ~200 | $0.14 / 1M | ~$0.00003 |
| 词汇入库 Embedding | ~50/词 | $0.02 / 1M | ~$0.000001/词 |

### 典型日用量（Erika 聊 10 轮）

| 项目 | 估算 |
|------|------|
| Embedding | 10 × 20 = 200 tokens ≈ **$0.000004** |
| Chat | 10 × 500 = 5,000 tokens ≈ **$0.0007** |
| **日合计** | **≈ $0.001**（约 ¥0.007） |

### 月成本估算

| 场景 | 对话轮数/天 | 月成本 (USD) |
|------|------------|--------------|
| 轻度（Erika 日常） | 10 | ~$0.03 |
| 中度 | 30 | ~$0.10 |
| 重度 | 100 | ~$0.30 |

### 一次性索引成本

| 项目 | 估算 |
|------|------|
| 全量索引 5583 chunks | ~280K tokens ≈ **$0.006**（一次性） |
| 增量索引 1 个新词 | ~50 tokens ≈ **$0.000001** |

### 成本控制措施（已实现）

- Embedding **缓存**在 `KnowledgeChunk`，仅 upsert 时重算
- 长对话才触发 **摘要压缩**（> 3000 token 阈值）
- Chat `max_tokens: 500` 上限
- `npm run ai:index:incremental` 跳过未变更内容

## 6. 复现方法

```bash
# 终端 1：启动 dev（记下端口，默认 3000 或 3001）
npm run dev

# 终端 2：跑 benchmark
BENCH_BASE_URL=http://localhost:3001 npm run ai:bench

# 生产 RAG 测试
BENCH_BASE_URL=https://jaylin-love-erika.vercel.app npm run ai:bench

# 重新生成本报告（会更新 RAG 生产数据）
```

**前提：** `.env` 中 `SESSION_SECRET`、`DEEPSEEK_API_KEY`、`OPENAI_API_KEY` 已配置；生产 SSE 自动化需 `SESSION_SECRET` 与 Vercel 环境变量一致。
